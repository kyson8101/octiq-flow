现在的 personaHue（web/src/lib/agentPersona.ts:90）是 hash % 360，整圈色相都会用到。头像的饱和度和亮度是固定的（hsl(h 62% 52%)），所以只要色相落在橙到黄这一段，头像就是琥珀色，和 --warn（深色约 38°，浅色约 45°）读起来一样。下面的名字和色相取自 2026-10-12 的真实名册（按 agent id 算，和页面一致）。

映射方式：色相没落在这一段的 agent 颜色不动；落在里面的，按它在这一段里的位置，等比例铺到段外的整圈上，所以仍然是"同一个 agent 永远同一个颜色"，原来挨着的几个也会被拉开。另一种做法是全员重排（80 + hash % 290），分布更均匀，但每个 agent 的颜色都会变一次，我不建议。上面卡片里的头像用的是这里选中的方案。

      
为什么我建议连红色一起避开：只避开琥珀时，WS LEAD 会从 76° 落到 353°，正好是 --danger 的红；名册里本来也有头像贴着这段红。红色头像读起来像"出错"，和琥珀读起来像"警告"是同一个问题。连红色一起避开后，没有头像会落在红或琥珀上。绿（--ok）和青（--decide）没法再避，否则剩下的颜色太少，分不开人。

样稿守住的规则

      
    
        
  • 等你决定用 --decide（边框、淡底、主按钮），不用 --accent，不用琥珀。输入框的发送键是 Claude 的模型色，放在旁边正好看出区别。
    • 
        
  • 信封行是卡上唯一的展开控件，折叠时只写标签和大小，不露正文的任何一截。展开后是全文，在卡片里滚动。
    • 
        
  • 控件在它打开的内容上方，内容在按钮上方。卡片贴着输入框向上长，展开或收起后指针下面都不是按钮；另外照 lib/pressGuard 的做法，按过信封后 700 毫秒内、8 像素内落在别处的重复按压会被丢掉。
    • 
        
  • Cancel / Keep it here 在等待状态下永远可按。内容太长时主按钮关着但留在原位（aria-disabled），说明句以正文的强度站在信封的位置。
    • 
        
  • 动效：展开 200ms，确认后头像和名字 200ms 飞到标题，都是 ease-out、不回弹；"正在打开"时只有头像外圈在呼吸，外圈是卡片文字的灰色，不是 --accent（这时还没有回合在跑，而强调色在 Claude 下是金色），也不是 --decide（这时已经不等你决定）。系统开了"减少动态效果"时全部直接到位。
