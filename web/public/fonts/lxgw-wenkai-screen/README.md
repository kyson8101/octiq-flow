# LXGW WenKai Screen

OctiqFlow bundles the Screen face from `lxgw-wenkai-screen-webfont@1.7.0`
(upstream font version v1.250.2), using its WOFF2 Unicode subsets for on-demand loading.

- Font project: https://github.com/lxgw/LxgwWenKai-Screen
- Webfont package: https://github.com/chawyehsu/lxgw-wenkai-webfont
- Font license: SIL Open Font License 1.1, reproduced in `OFL.txt`.
- Webfont packaging license: MIT, reproduced in `LICENSE`.

Only `lxgwwenkaiscreen.css` is imported; the package's other faces are not bundled.
